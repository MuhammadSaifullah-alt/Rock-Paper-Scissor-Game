Rock Paper Scissors Game:

A simple and interactive Rock Paper Scissors game built using **HTML, CSS, and JavaScript**. Players can choose Rock, Paper, or Scissors, while the computer randomly generates its move. The game determines the winner, updates the score, and displays the result with visual feedback.

Features:

* Interactive Rock, Paper, and Scissors selection
* Random computer move generation
* Real-time game result display
* Green background message for wins
* Red background message for losses
* Scoreboard tracking player and computer scores
* Clean and responsive user interface

How It Works:

1. The game starts with a **"Make Your Move"** message.
2. The player selects Rock, Paper, or Scissors.
3. The computer randomly chooses its move.
4. The game compares both choices and determines the result.
5. A message is displayed indicating whether the player won, lost, or drew.
6. Scores are automatically updated on the scoreboard.

Technologies Used:

* HTML5
* CSS3
* JavaScript
